# quiz-website
Online quiz application

## About
This is the GitHub repository for an online quiz website. This application utilizes the client-server architecture to decide which questions to include, when the game starts, keeping track of the score and serving the HTML/CSS/JS files.

## Project Structure
```
quiz-website/
│
├── index.html          (Home page)
├── play.html           (Gameplay page)
├── results.html        (Results page)
├── signup.html         (Sign up page)
├── login.html          (Log in page)
│
├── css/
│   └── styles.css
│
├── js/
│   └── script.js
│
└── assets/
    └── images/
```

## How to Play
Visit the quiz website [here](https://jesseazizi.github.io/quiz-website/).

## How to Run
To host your own version of the website, clone this repository and either run it on your own web server or through GitHub Pages.
